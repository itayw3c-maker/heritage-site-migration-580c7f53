# סנכרון GitHub — שחרור הפער ודחיפת הקוד העדכני

## מה נבדק עכשיו (עובדות, לא הנחות)

- צד Lovable נקי ומתויג: הראש המקומי והענף המרוחק של Lovable זהים — `7ec5c64 Fixed decodeIfValid round-trip`. כל תיקוני ה-SEO מ-6–7 בספטמבר כבר בקומיטים.
- הריפו `itayw3c-maker/heritage-site-migration-580c7f53` פתוח לקריאה מהסביבה, ו-`main` שם עומד על `13ae1d5`.
- נקודת הפיצול: ל-GitHub יש **8 קומיטים** שלא קיימים בקו של Lovable, ול-Lovable יש **204 קומיטים** ש-GitHub לא רואה. פיצול כזה חוסם סנכרון דו-כיווני אוטומטי (אין fast-forward) — ולכן שום דבר לא זורם בין הצדדים כבר שבועיים.
- בדקתי תוכן-מול-תוכן את כל 8 הקומיטים של GitHub מול הגרסה הנוכחית כאן: **כולם כבר כלולים בפועל** —
  - גלריית נזקים בפוטר: קיים (אותו קישור, רק מקודד);
  - אייקון שיחה בנייד בכותרת: קיים;
  - תיקון הלחיצה הכפולה בתפריט: קיים;
  - `overflow-x: visible` + גופן המותג + צבע כפתור הטופס: קיימים;
  - הקו התחתון בסכום הפשרה: קיים;
  - שכתוב פסקת הפתיחה במאמר לוחות הזמנים + תמונת הנזק: קיימים;
  - כותרת H1 של דף הבית: קיימת, ואף עם שיפור מקומי מאוחר יותר (תוספת ירידת שורה מבוקרת).

מסקנה: אין שום תוכן למשוך מ-GitHub. GitHub פשוט מיושן, וצריך לזרים **Lovable → GitHub**.

## מה אעשה

### 1. שחרור הסנכרון בגישר היסטוריה
אמשוך את `main` של GitHub לעותק מקומי ויצור קומיט גישור שמכריז רשמית ש-`13ae1d5` הוא אב-קדמון של הקו הנוכחי, **בלי לקחת ממנו אף קובץ** (`git merge -s ours`). זה בדיוק אותו מרפא שהצליח באוגוסט, רק בכיוון ההפוך.

### 2. איכות-אפס-שינוי
- וידוא שהעץ אחרי הגישור זהה בתים-בתים לעץ שלפניו (`git diff` ריק מול `7ec5c64`).
- הרצת בדיקות ובנייה — צפויות 71/71 ו-build OK, כי לא געתי בתוכן.

### 3. דחיפה ואימות
אאשר ש-`main` של Lovable התעדכן, ואז (בעותק מבודד) אבדוק שוב ושוב בהמתנה מוגבלת עד ש-`main` של GitHub יגיע ל-`7ec5c64` (הסנכרון צריך לקבל fast-forward — כעת יש לו). אם הסנכרון לא מזרים לבד תוך ~2 דקות, אדווח לך ללחוץ resync בפאנל ה-GitHub ולא אנסה שוב ושוב.

### 4. מה לא אעשה
- לא אפרסם ולא אריץ deploy — הפריסות נמשכות מקומיטים ב-GitHub, והצעד הזה יביא לשם את הקוד; אתה תפעיל את ה-deploy.
- לא אשנה אף קובץ תוכן, עיצוב, redirect או sitemap.
- לא אכפה היסטוריה (force push) ולא אמחק את 8 הקומיטים של GitHub — רק יצרף אותם כאבות.
